## 一、动机：唯一没被否证、且有量化证据的方向

战术层「再加强」四条路已全部量死（MEMORY 2026-10-13 置顶条目）：

| 方向 | 结论 |
| --- | --- |
| ① 恢复防守预算（v14.3） | 机制真实但只改 0.83% 局面，120 局跑下来**比分更差** |
| ② 恢复 pressureGate | 只在「无链」桶的 2.2%–6.8% 局面开火，几乎空转 |
| ③ 形状/位置评估 | 留出集天花板 top-1 6.82%、top-10 30.3%，且**只在开局有效**（中盘 0.00%） |
| ④ 候选集截断 | 890 个有链局面里「只有全量视野才拆得掉」= **0**，无收益 |

**模型侧是唯一没被否证的方向**，而它有一条具体、可量化、可修的发现
（`.work/model-side.mjs`，vplus-r10s 全部 120 局）：

- 模型自选着法 **722 手**（无接管层开火、ply ≥ 4）中，**带战术标签 252（34.9%）**，
  其对局**不败率 69.4%**；**不带标签 470（65.1%）**，不败率 **80.4%**（基线 76.6%）。
- **模型选了带标签的点，结果反而更差 11 个百分点。**
- 且这 252 手的标签构成**高度单一**：`you:four` 230（91.3%）、`you:live3` 22（8.7%）；
  `win` / `block:five` / `deny:*` **一个都没有**——那些局面已被接管层拦走，模型没机会选。

**读法**：`you:four` / `you:live3` 是**正向措辞的进攻标签**，它们在把模型往激进取势上带，
而这类走法与更差的对局相关。模型三分之一的自选着法带着这种标签，其中「造四」独占九成。

**注意这是相关不是因果**：带 `you:four` 标签的局面本身往往就是「双方都在造杀」的激战，
差的对局可能是因为局面难。**本轮实验就是为了把这个相关变成因果判定。**

## 二、v15 改什么（一句话规则）

> **不告诉模型「这一步造四 / 造活三」，除非它同时也是防守要点（`deny:*` / `block:five`）。**

- **单变量**：只改 `labelPoint()` 的**标签输出**，`deny:open4` / `deny:four` / `deny:live3` /
  `block:five` / `you:open4` / `win` **全部保留**。
- **接管链零改动**：`parry3` / `parry4` 扫的是 `deny:*` 标签，**不受影响**；
  `open4` 层扫 `you:open4`，也不受影响。⇒ 本档**不会削弱任何战术层**。
- **预算与 mech 其余键**：与 `v14-plus` **逐键相同**，只多一个 `quietShape` 开关。
- **实现**：`serializeForJev` 增加可选第三参 `opts.quietShape`，`client.ts` 按
  `M.quietShape === true` 传入；老档不带该键 ⇒ 输出**逐字不变**（指纹测试钉死）。

**为什么保留 `you:open4`**：活四是「对手挡不住的直接胜势」（2 手内必胜），是**真事实**，
和「造四」（对方有一步应手）性质不同，不该一起砍。

## 三、预注册判定规则（跑前写死）

### 实验 A：`v15` vs `v14-plus`（jevrouter 双臂，同开局换色配对，120 局）

| 判据 | 层级 | 通过条件 |
| --- | --- | --- |
| **机制层：模型自选着法里带 `you:four`/`you:live3` 的比例** | **主** | v15 臂该比例**低于** v14-plus 臂（这是改动是否生效的直接可观测后果） |
| 规则 11：负局不增加 | 硬底线 | v15 臂负局 ≤ v14-plus 臂 |
| 规则 11：不败率不下降 | 硬底线 | v15 臂不败率 ≥ v14-plus 臂 |
| 比分统计量 | **只报不判** | 逐对分差均值 + 配对 95% CI，如实报 |

**比分为什么只报不判**：`vplus2` 的教训——60 对样本在 ±20pt 的同族方差里**没有统计功效**
（该项目已连续四次在同族轨迹改写上落到噪声带）。本轮以机制层为主判据。

### 实验 B：`v15` vs Rapfi@10s（120 局，同 seed/上游/store）

## 五、已知的下行风险（所以必须是 A/B 而不是直接替换）

1. `you:four` 也可能是**真信息**——模型靠它识别这步有战术价值。砍掉可能让模型变瞎。
2. 局面难度与标签共变（见第一节的「相关非因果」），可能出现**机制层生效但比分更差**的情况——
   那与 v14.3 是同一类结果，说明「标签诱导」也不是有效杠杆。
3. 若两轮都不通过，本轮结论即：**模型侧的 `you:four` 相关性也是假相关**，模型侧需要另找抓手。
