## 1. 问题：面板上的「72% 优势」从来没人验证过

现状：决策面板每手都显示「白方优势 72%」（`meta.noul`），趋势图画胜率曲线，战绩簿记胜负。
**但整条链路没有任何一处检验这些百分数是否可信。** 一个永远输出 50% 的模型和一个真正
会算的模型，在当前 UI 上看起来毫无区别。

「零幻觉」在 memory 里被限定为「仅指输出结构体」——那么**结构体里的数字准不准**，就是
这个项目最该回答而没回答的问题。这正是校准（calibration）要回答的：

> Jev 说「70%」的那些时刻，最后真的有 70% 兑现吗？

## 3. 设计

### 3.1 数据：已经在手，只需持久化

- 每次 AI 决策的 `meta.noul`（0–1，**行棋方**视角）经 `buildSeries` 的 `flip` 换算为
  **先手方**视角的 `win`。
- 真值 `y` = 该局终局结果：先手方赢 `1`、输 `0`；**和棋不入样本**（二元事件无真值，强行
  记 0.5 会污染 ECE）。
- 现状缺口：`saveGameRecord` 只存摘要，不存逐手预测。修法：记录里加
  `cal`（逐手先手方胜率，**只收非演示渠道**——mock 的概率是合成的，混进去等于自欺）、
  `gid`（引擎 id，用于分组）。

### 3.2 指标：只上「能证明对」的四个

刻意**不采用** Murphy 的 `BS = REL − RES + UNC` 三分式。推导时发现该恒等式在
「分箱内预测值非常数」时并不成立（对完美预测 `p=y∈{0,1}` 代入即证伪：公式给 0.25，
真值 0），需要额外的箱内方差修正项才严格。为避免发布一个自己无法证明的分解，
改用下列**定义即真值、无恒等式依赖**的指标：

| 指标 | 定义 | 读法 |
|---|---|---|
| `brier` | `mean((p−y)²)` | 越低越好；0.25 = 全猜 0.5 |
| `skill` | `1 − brier / (p̄(1−p̄))` | **相对「恒定猜真实基准率」的技巧分**。0 = 毫无信息量，1 = 完美 |
| `ece` / `mce` | `Σ(n_k/N)·|acc_k−conf_k|` / 其最大值 | 分箱校准误差（L1 形式） |
| `overconfidence` | `mean(p) − p̄` | >0 = Jev 平均比现实更乐观 |

`skill` 的分母是「恒定基准率」这一参考预报的 Brier，因此它是**恒定义良好**的
（`p̄∈{0,1}` 时分母为 0 → 返回 `null`，面板显示「—」）。

### 3.3 关键洞察（本特性真正的价值所在）

**ECE 会骗人。** 两个预测器的 ECE 可以都是 0（完美校准），而技巧天差地别：

- 预测器 A：`p∈{0,0.5,0.5,1}`，结果 `y∈{0,0,1,1}` → `brier=0.125`、`ece=0`、`skill=0.5`
- 预测器 B：`p≡0.5`，结果同�� → `brier=0.25`、`ece=0`、`skill=0`

B「从不撒谎」因为它从不下注；A「撒谎得少」**而且有信息量**。因此面板必须把
`skill` 与 `ece` **并排给出**，并在图例里写明二者不可互相替代。这不是文案装饰，
是夹具实测出来的结论。

### 3.4 模块边界

新建 `js/calibration.js`：**纯函数、零 DOM、零依赖**，可在 Node 直接加载自检
（与 `board.js` 同类角色）。只做数学，不碰 UI、不碰引擎、不碰 localStorage。

```
BG.calibration = { clean, reliability, metrics, fromRecords, selfTest }
```

- `reliability(samples, nBins)` — 等宽分箱，返回每箱 `n / conf / acc`（可靠性图数据源）
- `metrics(samples)` — 四个指标；样本不足返回 `null`
- `fromRecords(records)` — 从战绩簿汇总（剔除演示样本与和棋）
- `selfTest()` — 解析夹具自检，供 `?test=1` 浏览器同源运行

### 3.5 展示

侧栏新增「校准实验室」面板：技巧分大数字 + 四个指标瓦片 + 可靠性图
（`charts.reliability()`：对角参考线 + 每箱「偏离对角线的竖线 + 落点」+ 箱计数直方图）。
样本不足时显示诚实的空态，而不是画一张假图。

### 3.6 诚实性约束（写进实现注释）

同一局内所有样本共享同一真值 `y`，因此样本**按「局」强相关**，有效样本量更接近
**局数**而非手数。面板同时显示「N 局 / M 手」，不谎称样本量。

1. `js/calibration.js` 的 `selfTest` 用**解析夹具**断言（ECE/skill/brier/过度自信
